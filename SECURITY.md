# Security Policy

Fallback Atlas is currently a prototype. Report submission is browser-local and there is no shared reporting API.

## Reporting a vulnerability

Please do not publish secrets, access tokens, private personal information or a working exploit in a public issue.

Use GitHub's private vulnerability reporting for this repository if enabled. Otherwise, contact the repository maintainer through GitHub and request a private channel. Include the affected file or component, impact and concise reproduction steps.

## Scope

Security-relevant areas include dependency vulnerabilities, cross-site scripting, unsafe report rendering, accidental collection of precise location, exposure of credentials, and weaknesses in any future API or shared data store.

Please do not test against third-party services in ways that violate their terms or disrupt availability.
